# Learning Loop Checklist

- [ ] Name the observed learning.
- [ ] Identify affected context.
- [ ] Identify source signal: review, handoff, incident, retrospective, evaluation, test, schema validation, or implementation result.
- [ ] Decide whether the lesson is local or shared.
- [ ] Decide whether it belongs in docs, ADRs, schemas, examples, checklists, or `AGENTS.md`.
- [ ] Preserve origin, owner, scope, rationale, source basis, and review state for shared learning.
- [ ] Preserve uncertainty when evidence is incomplete.
- [ ] Add or update tests when behavior changes.
- [ ] Propose instruction changes for recurring mistakes.
- [ ] Review the memory update.
- [ ] Define a later check when the update is meant to reduce repeated failures.
