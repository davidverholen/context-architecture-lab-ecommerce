# Architecture Change Checklist

- [ ] Read `docs/context/index.md`.
- [ ] Read `docs/commerce/index.md`.
- [ ] Identify affected bounded context.
- [ ] Identify neighboring contexts and semantic owners.
- [ ] Identify source authority.
- [ ] Classify required, optional, forbidden, and missing-authority context.
- [ ] Check relevant ADRs.
- [ ] Define required context pack.
- [ ] Identify required handoff.
- [ ] Confirm handoff obligations are closed or explicitly blocking.
- [ ] Classify risk level.
- [ ] Identify decision rights, accountable owner, and evidence required.
- [ ] Confirm MVP v0.1 exclusions are not being added implicitly.
- [ ] Update or explicitly confirm durable memory.
- [ ] Record open questions.
- [ ] Propose an `AGENTS.md` diff for durable agent operating-rule changes.
